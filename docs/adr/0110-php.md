# ADR-0110: PHP

- **Status:** Accepted
- **Decides:** The dev shell and checks use PHP 8.5 from the pinned Nix input.

## Context

The project needs a PHP runtime for its command and tests. The PHP line also sets the syntax the tools accept.

## Decision drivers

1. **Support.** PHP receives bug fixes and security fixes.
2. **Tool fit.** The runtime and the tools that parse its code work on the same PHP line.
3. **Use in web apps.** The same runtime can serve a Laravel 13 project if a project adopts that framework.

## Considered options

| Option | 1 Support | 2 Tool fit | 3 Use in web apps | Verdict |
| --- | --- | --- | --- | --- |
| PHP 8.4 | Active support through 2026 | Supports PHPUnit 13 and uses older PHP syntax | Listed for Laravel 13 | Good when a project must support older PHP |
| **PHP 8.5** | Active support through 2027 | Available at the Nix pin and verified with Composer, Mago, and PHPUnit 13 | Listed for Laravel 13 | **Chosen** |
| PHP 8.6 | The newest stable line and the longest support window of these options | Available at the Nix pin and has newer syntax for tools to support | Outside the published Laravel 13 support matrix | Good when a project needs 8.6 features and its stack supports them |

### Sources

- [PHP supported versions](https://www.php.net/supported-versions.php) and [PHP 8.6 release](https://www.php.net/releases/8.6/en.php).
- [PHPUnit support table](https://phpunit.de/supported-versions.html) and [Laravel 13 support table](https://laravel.com/docs/13.x/releases#support-policy).
- [Nixpkgs PHP packages](https://nixos.org/manual/nixpkgs/unstable/#sec-php) and [Mago config](https://mago.carthage.software/1.59.0/en/guide/configuration/).

## Decision

The dev shell and the checks use `pkgs.php85`. The Composer manifest accepts the 8.5 line. Mago parses PHP 8.5.

## Consequences

The project can use PHP 8.5 syntax and standard library functions. A project that needs an older runtime also needs checks for that runtime.

A PHP minor upgrade changes the Nix package, the Composer constraint, and the Mago target in one change.

## Rules

- The Nix runtime, Composer requirement, and Mago syntax target use the same PHP line.
- Composer validates the lock against the runtime and its extensions. `(CI: lint-php)`
